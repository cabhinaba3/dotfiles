Only `conf.toml` (skin + verbs) and `broot_wrapper.sh` (the `br` shell
function) are hand-authored config, so that's all this repo tracks.
`~/.config/broot/launcher/`, `skins/`, `verbs.hjson` and `conf.hjson` are
generated by broot itself the first time it runs (`broot --install` or
just launching it) — `install.sh` doesn't need to reproduce them.
